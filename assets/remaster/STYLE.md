# Industrial arena v1 — production style sample

This style is a production proposal, not an exact remake of absent commercial
source data. Remake/publication and unlimited generation were authorized on
2026-09-09; each third-party input still needs provenance. The first sample uses
an original text brief only, without extracted commercial textures or meshes.

- Large graphite structural frames, warm ivory armor, restrained cyan energy
  and small orange connectors. No borrowed logos, writing or tiny surface noise.
- Prioritize clear silhouettes and target visibility in motion. Emission is an
  accent, not a full-screen bloom/light source. Team identification cannot depend
  solely on color. This sample does not establish team palette or gameplay use.
- Concept views must show the whole isolated object. Single-image 3D infers the
  hidden back; inspect it explicitly. Before modular production require matching
  front/back/sides and measured connector drawings. Do not treat a generated
  perspective image as a dimensionally accurate orthographic blueprint.
- Blender master: meters, Z up, ground-centered pivot, uniform scale. Export:
  40 Q3 units/m, explicitly recorded Z rotation; check front direction in engine.
- First static sample: 1.6 m high, target 1800 triangles, one baked 1024px diffuse
  surface. This is a traditional compatible material baseline, not PBR fidelity.
  Preserve the raw PBR GLB for later normal/roughness/metallic work.
- Visible geometry must originate in image → generated mesh → Blender. The
  preview camera/lights are inspection equipment, never exported game assets.
- Character production is IQM-first in the main engine workstream. This tool's
  static one-frame MD3 exporter intentionally rejects animated/rigged assets;
  it is not a character pipeline and must not silently flatten one.

Human gates: prototype identity/readability → geometry/front/back inspection →
material inspection → actual ioq3 browser review. Automated reports and Blender
renders never set runtime approval. Revision an asset rather than overwrite a
paid operation when a new concept is needed.
